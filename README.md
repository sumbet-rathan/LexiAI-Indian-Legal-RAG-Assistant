# LexiAI-Indian-Legal-RAG-Assistant
LexiAI is a Retrieval-Augmented Generation (RAG) system for Indian legal research. It ingests legal PDFs and text, retrieves relevant sections with hybrid search (MMR + BM25), and produces cited answers with GPT-4o-mini. It also converts old IPC section numbers to the new BNS numbering. Built with LangChain, Ollama embeddings and ChromaDB.
